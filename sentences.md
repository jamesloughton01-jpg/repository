# Simple Sentences

Short, grammatically simple, mostly self-contained clauses pulled from
the texts already in this repository — distinct from `phrases.md`, which
collects longer or more famous passages. These are meant for quizzing:
short enough to parse word-by-word using `vocabulary.md` and
`grammar.md`. Where a clause is extracted from a longer sentence, the
source is still the original text; punctuation/capitalization is
normalized for readability. Sources: see the individual texts in
`texts/` and the poem/prose citations below for full attribution.
