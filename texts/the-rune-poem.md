# The Rune Poem

94 lines, 29 stanzas, one for each letter of the Anglo-Saxon futhorc
(runic alphabet). Each stanza uses the rune's name as its subject,
describing what that concept means or does — e.g. Feoh ("wealth"), Ur
("aurochs"), Thorn, Ing, Dæg ("day"). The original manuscript (Cotton Otho
B.x) was destroyed in the 1731 Cotton library fire; it survives only
because George Hickes transcribed and published it in 1705. Old English
text: sacred-texts.com, Cook & Tinker, *Select Translations from Old
English Poetry* (1902), public domain. The manuscript itself opened each
stanza with the rune character standing in for its name-word rather than
spelling the word out; Hickes's edition (like most modern ones) spells
the name out instead, for readability. This table restores the rune
glyph as a prefix on each stanza's first line — see the Runes tab for
what each one means — while keeping the spelled-out reading alongside it.
Modern English translation: own work for this repository, prose
rendering (not verse).
